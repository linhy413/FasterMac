# Contributing

感谢关注 FasterMac！项目由 [linhy413](https://github.com/linhy413) 发起和维护。
欢迎提交问题复现、功能建议、使用体验和测试结果。请注明 macOS 版本、芯片架构、
组件名称和最小复现步骤；日志请先删除个人路径和敏感内容。

## Code contributions

This project currently accepts feedback first. Before opening a code PR,
discuss the proposed change with the maintainer. A code contribution will not
be merged until the contributor and maintainer have separately agreed in
writing on the rights needed for open-source distribution and possible
commercial/proprietary licensing, including any necessary patent grant.

Opening a PR does not automatically assign copyright or grant the maintainer
commercial relicensing rights. Contributors retain ownership of their work.
Do not submit employer-owned or third-party code without the necessary rights;
existing third-party licenses must be disclosed and preserved.

Before an agreed PR is reviewed, run `bash scripts/test.sh` and
`git diff --check`. Preserve existing copyright and attribution notices,
and identify your own modifications accurately. The full application's
private code is outside the scope of this repository.
